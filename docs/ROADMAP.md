# 로드맵

예전 웹 콘솔의 기능 원장을 옮긴다. SSH 작업대는 D1~D24, DB 작업대는 E1~E13 이다.
웹·서버 중계 때문에 있던 부품(끊김 유예·이어붙이기·흐름 창·배포 드레인·녹화·서버 감사·브라우저 폴더 우회)은 로컬 앱에서 필요 없어 옮기지 않는다.
첫 화면은 공용 콘솔 구조를 버리고 개인 도구로 다시 짠다(홈 = 내 연결·빠른 시작).

## 0.1 — 시제품 (지금)
- 앱 틀: 사이드바(OS 흐림)·탭 머리줄·Windows 창 단추·macOS 신호등 자리, 라이트·다크
- 로컬 터미널(ConPTY·pty), 출력 벤치(스파이크 1)
- 결과 표 시제품 10만 행(스파이크 5)
- 리눅스 명령어 사전 358개 한국어(데이터 그대로 이식)
- 접속 프로필 저장(SQLite), 자동 업데이트, 설치판·포터블·dmg

## 0.15.0 — DB 작업대 재배치·쿼리 지도 결과 흐름·쿼리 다듬기·DB 특화 자동완성·설정 화면 (2026-11-13)

- 설정 화면을 macOS 시스템 설정 구조로: 왼쪽 검색·범주(색 아이콘), 오른쪽 둥근 묶음 목록, 깊은 항목은 한 단계 들어가기, 초성 검색, 좁으면 목록 → 본문. 저장 키·값은 그대로, 바꾸면 열린 화면이 바로 따라간다
- DB 작업대: 머리줄(DB·버전·읽기 전용) / 쿼리 탭 줄 / 도구 막대(▷ 실행 강조 · 전체·계획·분석 | 포맷·쿼리 분석·기록·즐겨찾기·찾기·도구… | 오른쪽 자동 LIMIT·행 상한·시간·자동 커밋), 오른쪽 "쿼리 분석" 칸(구조·진단·인덱스·다듬기 탭), 0.14 배치 자동 이전. 지도가 다른 칸 위로 비치던 것·튜닝이 지난 문장을 보이던 것
- 쿼리 지도: 원본 표 → JOIN → WHERE → GROUP BY/HAVING → 창 함수 → DISTINCT → ORDER BY·LIMIT 이 최종 결과로 흘러 들어오는 그래프, CTE·서브쿼리·UNION 갈래 묶음, 결과 열 계보(올리면 강조·누르면 고정), 노드 ↔ 편집기 양방향 강조(서브쿼리 괄호·표·JOIN 절·WHERE…), 맨 위 "최종 결과" 띠(열 수·행 성격·열 칩 — 이름·출처·형식, UPDATE/DELETE/INSERT 는 대상·조건)
- 쿼리 다듬기(레거시 쿼리 정리): safe — 쉼표 조인 → INNER JOIN·(+) → LEFT JOIN·열 한정·짧은 별칭·1=1·중복 조건·괄호·IN 단일값·OR → IN·안 쓰는 CTE·군더더기 DISTINCT, check — 파생 표 펼치기(ORDER BY·ROWNUM 이 있으면 안 함)·반복 서브쿼리 → CTE·상관 집계 → LEFT JOIN·NOT IN → NOT EXISTS·안 쓰는 LEFT JOIN·HAVING → WHERE. 항목별 켜고 끄기, 결과 같은지 확인(SELECT 만, EXCEPT·집계 해시), 둘 다 EXPLAIN, 넣기는 Ctrl+Z 로 되돌림. 다시 파싱이 안 되면 내지 않는다
- DB 특화 자동완성: 절 문맥(SELECT·WHERE·ON·GROUP·ORDER·SET → 이 문장 표의 열, FROM·JOIN → 표·행 수), 별칭 제안, JOIN … ON 조건 한 줄(FK·같은 이름·이름 규칙), 열 형식·PK·IDX·NULL 표지, 엔진별 함수 서명, `*` 펼치기(Alt+Enter), 지금 DB 표가 안 나오던 것·대소문자 순위·실패 캐시 고침, DDL 뒤 캐시 비움, 설정 › 데이터베이스 › 자동완성 스위치
- 터미널: 한글 조합 중 앱 키 가로채기·흐린 제안이 끼어들어 순서가 뒤바뀌던 것(→·Tab·Enter), 조합 직후 Ctrl+C/V, 맥 WKWebView 자모 분리 우회. 터미널 cd 를 따라간 트리 스크롤. 긴 줄 접지 않기(Alt+Z)는 선택을 기억하고, 처음 접힐 때 한 번 알림, 설정 › 터미널 스위치, 전체 화면 프로그램 중에는 칸 폭
- 남음: 실제 한국어 IME·맥 실기 확인, 실DB 에서 다듬기 결과 비교·EXPLAIN, 쿼리 지도 INSERT 결과 행 계보, 다듬기 주석 위치(크게 바뀐 문장), 패닉 폴백(릴리스 panic=abort)

## 0.14.0 — 전체 점검(데이터 손실·성능)·쿼리 지도·튜닝 도우미 (2026-11-13)

- 쿼리 구조 지도(DB 작업대 "쿼리 지도" 칸): 치는 동안 서버에 묻지 않고 받아 둔 표·열·FK 로 지금 문장의 표·JOIN(종류·조인 열)·조건 열·CTE·서브쿼리를 그래프로. ON 없는 곱·FK 없는 조인·형식 다른 비교·없는 표/열 경고, 클릭하면 편집기 그 위치. 파서는 Rust sqlparser(PG·MySQL·MSSQL, 그 밖은 범용)
- 튜닝 도우미("튜닝" 칸): 정적 검사(SELECT *, 함수로 감싼 조건, 앞 % LIKE, 암묵 형변환, NOT IN+NULL, 큰 OFFSET → 키셋, 상관 서브쿼리, LIMIT 없는 정렬, 조건 없는 UPDATE/DELETE), 인덱스 검사(없으면 CREATE INDEX 초안 — 실행은 안 함), 실행 계획 규칙(큰 표 전체 스캔·예상/실제 행 10배·디스크로 넘친 정렬/해시·MySQL type=ALL·filesort), 바꿔 쓴 SQL 나란히 보기·둘 다 EXPLAIN
- 데이터 손실: 편집기 저장이 파일을 자르지 않아 짧게 고치면 옛 꼬리가 남던 것(SFTP TRUNCATE, 쓴 뒤 크기 확인·충돌 판정에 크기), 반영 전 DB 표 편집이 다시 실행·탭 닫기·앱 끄기 때 묻지 않고 사라지던 것, SQL 초안 마지막 입력, 경로 매핑 첫 반영이 서버 쪽 변경을 덮던 것
- 연결: 접속 창 대기열(여러 서버가 동시에 끊겨도 모두 다시 열림), 다시 연결 때 옛 연결 정리, 조용한 다시 연결(2·4·8초), 절전 복귀 감지, keyboard-interactive 는 암호 질문에만 1회(OTP 서버 잠김 방지), 인증·sudo·sha256 시간 상한, IPv6 가 막힌 망에서 IPv4 로(Happy Eyeballs), exec 채널 정리, PTY 좀비, 충돌 기록(crash.log)

- 기능: 홈 검색 Enter·`user@host:port` 빠른 접속, Ctrl+Tab·Ctrl+1~9·닫은 탭 다시 열기(Ctrl+Shift+T), 시작 때 세션 자동 복원(설정), 터미널 나누기·칸 최대화·칸 이동 단축키, `~/.ssh/known_hosts` 가져오기, 쿼리 기록의 암호 가리기
- 다듬기: 터미널 cd 를 따라간 트리가 그 폴더를 위로 올려 안이 보이게, Alt+Z 가 포커스 이동 때 풀리던 것, WebGL 문맥 손실 복구, 전송 칸이 다른 탭 전송과 섞이던 것

## 0.13.1 — 작업대 배치 복구·컨테이너 따라가기 안전장치 (2026-11-12)

- 터미널이 안 보이던 배치: Ctrl+` 로 숨긴 터미널 칸이 저장돼 되살아나고, 숨은 칸 위에 파일을 열면 오른쪽 100px 띠로 굳던 것. 숨김은 저장하지 않고, 되살릴 때 숨긴 칸을 보이게·빈 칸 지우기·터미널이 없으면 열기·최소 폭에 붙은 칸 펴기(처음 한 번, 가려진 채 열렸으면 보일 때). 숨은 칸을 기준으로 새 칸을 붙이지 않는다. 가려진 앱 탭에서는 배치를 저장하지 않고, 보이게 되면 다시 그린다. 칸 막대에 "터미널" 단추, 트리를 다시 열면 기본 폭
- 컨테이너 훅 넣기 안전장치: 셸 프롬프트 모양일 때만 넣는다(sudo 암호·확인 질문·전체 화면 프로그램에 넣지 않음, 암호 뒤 프롬프트가 뜨면 그때). 명령 머리가 docker/podman 일 때만(`ssh 다른서버 docker exec` 는 아님), -H·--context 는 제외. 에코가 오기 전에 Enter 를 눌러도 친 키로 명령을 읽는다
- Docker 칸 "컨테이너 안 셸" 도 트리·편집기가 따라간다
- 터미널마다 맥락: 트리는 지금 쓰는 터미널을 따르고(뒤 터미널의 프롬프트로 바뀌지 않음), 트리 → 터미널 cd 는 둘이 같은 곳일 때만, 경로 자동완성도 그 터미널 쪽 파일
- 경로 링크는 그 줄이 찍힐 때의 맥락으로 열고, 다른 맥락(ssh·su·tmux 등)에서 찍힌 경로는 물어본다
- 다른 맥락 띠(Orbit 과 같은 규칙): ssh·mosh·su·sudo -i·tmux·screen·kubectl exec·docker run/attach·compose exec 등에 들어가면 "트리·편집기는 이 서버 기준" 띠 — 프롬프트가 돌아오면 걷힘. 컨테이너에 훅을 못 넣었으면 띠의 "컨테이너로 트리 열기"
- Ctrl+Z(종료 코드 147~150)는 실패가 아니라 "⏸ 정지"(알림 없음). 작업 목록은 jobs -s/-r 로 나눠 받아 한국어 로캘에서도 뜨고, 구분자는 ASCII(EUC-KR 터미널에서도)
- 명령 사전 "터미널에 넣기" 는 프롬프트일 때만(전체 화면 프로그램·실행 중 명령에 넣지 않음)
- 컨테이너 bash 의 원래 PROMPT_COMMAND 를 잇는다, 컨테이너 저장은 임시 파일에 다 받은 뒤 덮어쓰기
- 남음: 컨테이너 ↔ 내 PC 전송, 같은 파일을 터미널 vim 이 열고 있을 때 알림(스왑 파일), 서버 쪽 앞 프로세스 확인(ps), docker exec -u 계정으로 파일 쓰기. tmux 모드·fish·csh 셸은 훅이 없어 따라가기·띠 판정이 꺼진다

## 0.13.0 — 컨테이너 따라가기·jobs·가로 스크롤 (2026-11-12)

- 터미널에서 `docker exec -it 컨테이너 bash`(podman·sudo·-u·-w·sh·zsh 포함)로 들어가면 그 셸에 프롬프트 훅을 넣어(에코는 숨김) 트리·편집기가 컨테이너 파일을 본다. exit 하면 서버 트리로 돌아온다 — "마지막으로 프롬프트를 그린 셸" 기준이라 Ctrl+Z·fg 로 오가도 맞다. 터미널을 여러 개 띄웠으면 초점을 옮긴 터미널 쪽으로
- 컨테이너 파일은 서버의 docker exec 로 읽고 쓴다(sh·stat·cat 만 — alpine·busybox 도). 소켓 권한이 없으면 계정 sudo 설정을 따른다. 트리 머리에 "컨테이너 이름" 띠와 "서버 트리" 단추, 편집기 탭에 컨테이너 이름. 경로 자동완성도 컨테이너 쪽
- 컨테이너 트리에서는 끌어 놓기·올리기·받기·실시간 보기·비교·다른 서버로 보내기를 끈다(서버 경로로 잘못 가지 않게) — 컨테이너 ↔ 내 PC 전송은 다음
- 셸 작업(jobs): 상태 줄 "멈춘 작업 N" — 눌러 앞으로(fg), vim·nano·less 로 멈춘 파일은 앱 편집기로 열기(터미널 쪽은 멈춘 채로 둔다)
- 다른 셸이 보내는 OSC 7(컨테이너·다른 서버의 프롬프트)을 이 서버 트리에 열지 않는다
- 터미널 줄 바꾸지 않기(가로 스크롤): Alt+Z·우클릭 메뉴. docker ps 같은 긴 줄을 접지 않고 Shift+휠로 옆으로, 치는 동안 커서를 따라간다
- 접힌(화면 폭을 넘는) 명령을 기록·명령 표시에 끝 조각만 남기던 것 고침

## 0.12.2 — 서버끼리 바로 보내기 (2026-11-11)

- 서버 → 서버 보낼 때 방식을 고른다: **서버끼리 바로**(보내는 서버가 받는 서버에 직접 접속해 rsync, 받는 쪽에 rsync 가 없으면 scp — 내 PC 회선을 안 씀, 보내는 서버의 키가 받는 서버에 있어야 함) / **내 PC 거쳐서**(지금까지의 중계). 지난번 고른 것을 위에
- 바로 보내기가 안 되면(키 없음·서버끼리 막힘·호스트 키 다름 등) 전송 칸에 까닭을 사람 말로 보이고 "내 PC 거쳐서" 단추로 바로 다시. 진행률(rsync progress2, scp 는 받는 쪽 크기)·취소(보내는 서버의 rsync/scp 에 TERM)
- "다른 서버" 단추를 늘 보인다 — 연결된 다른 서버가 없으면 저장한 서버를 골라 연결하고, 지금 탭에 머문 채 옆 칸에 그 서버 트리를 연다
- 서버 → 서버 전송이 끝나면 받는 서버 트리를 새로 읽는다(전에는 내 PC 트리를 새로 읽었다)
- 좁은 파일 칸에서 "연동" 글자가 세로로 쪼개지던 것 — 좁으면 아이콘만

## 0.12.1 — 자동완성 되살리기·편집기 다듬기·전체 점검 (2026-11-11)

- 터미널: 칠 때는 목록을 띄우지 않고 Tab 으로 목록(기본으로 되돌림, 설정 "Tab 키 = 셸 완성"이면 Ctrl+Space). 계산 중 온 Tab 은 버리지 않고 차례로(연타로 파고들기). "치다 멈추면 목록" 방식은 ↑↓ 로 고른 뒤에만 Enter 가 넣기
- 셸 통합: 로그인 셸을 알아내지 못해도(exec 거부·느림) bash 일 때만 걸리게 감싼 훅을 보낸다 — 0.12.0 에서 그런 서버는 프롬프트 표식이 없어 자동완성이 통째로 꺼졌다
- 편집기: 글 위 마우스 포인터 I자(앱 전체 cursor: default 를 이어받아 화살표였다), 상태 줄 자동 저장 스위치(멈추면·포커스 떠날 때·둘 다, 자동 저장됨 시각·실패 다시), 미니맵(기본 켬), JSON 문법 오류 표시, 낱말 완성은 두 글자부터·잠깐 멈추면, 팝업 불투명
- 앱을 다시 열면 열려 있던 편집기 탭을 되살린다(다른 서버 칸 파일 제외, 12개까지). 파일 트리 T(여기서 터미널)·L(실시간 보기)
- 전체 점검(영역별 리뷰): sudo 전환·주석 편집으로 고친 내용이 사라지던 것, 펼친 적 없는 폴더에 끌어 놓을 때 묻지 않고 덮어쓰던 것, 서버 안 복사 따옴표(명령 주입), 포워딩 채널 하나가 연결 전체를 멈추던 것, 끊긴 tar 받기를 성공으로 보던 것, PG 트랜잭션 안 행 상한이 커밋을 되돌리던 것, `BEGIN;` 뒤 문장이 합쳐지던 것, 실행 중 Ctrl+Enter, 원격 출력 ack, 한글 프롬프트 자동완성 위치 등
- 다듬기: 파일 트리 머리줄 두 줄·터미널 연동 단추, 상태 줄 잡음 줄이기, Ctrl+W 는 편집기 칸만(Ctrl+Shift+W 는 서버 탭), 우클릭 메뉴 단축키 정렬·키보드·초점 복귀, 글자 아이콘을 그린 아이콘으로
- 남음: 저장 전 바뀐 곳 확인(Orbit 은 늘), 같은 파일 나란히 보기, JSON·XML 정렬을 보기 전용으로, 전송 이어받기 원본 확인, DB 매개변수 바꿔 넣기·필터 중 새 행·PG 열 형식

## 0.12.0 — 서버 ↔ 서버·출력 흐름 제어·터미널 우선 배치 (2026-11-11)
- 다른 서버 칸: 열려 있는 다른 SSH 연결의 트리를 작업대 옆에, 트리끼리 끌어 놓으면 서버 ↔ 서버(중계, sha256·이어 보내기·충돌 시트), 다른 서버 파일 편집
- 출력 흐름 제어: 화면이 그린 만큼(ack)만 더 보낸다(창 512 KB). SSH 는 채널을 멈추지 않고 앱 안에 모으며(최대 16 MB), PTY 는 읽기를 쉰다. 이미 온 출력은 묶어서 보낸다
- 단어 색칠은 보이는 줄만(꾸밈이 쌓이지 않음), 암호·해시 크레이트만 opt-level 3
- 셸 통합: 로그인 셸을 먼저 확인해 bash·zsh 에만 건다(그 밖은 아무것도 치지 않음). clear 대신 주입한 줄의 에코만 걸러 MOTD 가 남는다
- 자원 표시 폴링은 연결당 하나(터미널을 나눠도 한 번만 묻는다)
- 기본 배치 터미널 우선(v3), 도구 막대는 자주 쓰는 것만 + "도구 ▾", 터미널 안 Ctrl+Shift+F·F1 은 터미널 몫, 계정 하나·물을 것 없으면 서버 카드 없이 바로 접속
- 터미널 Ctrl+C/Ctrl+V(Windows Terminal·VS Code 규칙): 고른 글이 있으면 Ctrl+C 복사·없으면 ^C, Ctrl+V 붙여넣기(설정으로 ^V), macOS ⌘C/⌘V, 복사됨·실패 알림
- 남음: A→B 서버끼리 직접 전송(rsync/scp, 망이 닿을 때), 상태 줄을 작업대 한 줄로 합치기
