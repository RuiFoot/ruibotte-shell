# 로드맵

예전 웹 콘솔의 기능 원장을 옮긴다. SSH 작업대는 D1~D24, DB 작업대는 E1~E13 이다.
웹·서버 중계 때문에 있던 부품(끊김 유예·이어붙이기·흐름 창·배포 드레인·녹화·서버 감사·브라우저 폴더 우회)은 로컬 앱에서 필요 없어 옮기지 않는다.
첫 화면은 공용 콘솔 구조를 버리고 개인 도구로 다시 짠다(홈 = 내 연결·빠른 시작).

## 0.1 — 시제품 (지금)
- 앱 틀: 사이드바(OS 흐림)·탭 머리줄·Windows 창 단추·macOS 신호등 자리, 라이트·다크
- 로컬 터미널(ConPTY·pty), 출력 벤치(스파이크 1)
- 결과 표 시제품 10만 행(스파이크 5)
- 리눅스 명령어 사전 358개 한국어(데이터 그대로 이식)
- 접속 프로필 저장(SQLite), 자동 업데이트, 설치판·포터블·dmg

## 1단계 — 첫 실사용판 (0.2.0, 2026-11-05 — ✅ 아래 "남음" 빼고 완료)
- SSH:
  - 프로필(암호·개인키·sudo 암호는 OS 저장소, 저장은 선택)
  - 구형 호환 4단계, 호스트 키 고정(TOFU)
  - 터미널 탭·분할·다중 채널, 셸 통합(✓/✗·cwd 따라가기)
  - 스크롤백·검색·링크, 터미널 인코딩(EUC-KR), 자동 재연결
- 파일:
  - 트리, 편집기(인코딩 판별·CRLF 유지), 이미지·JSON/XML/MD·CSV 미리보기
  - sudo 같이/따로
  - 양쪽 트리(내 PC↔서버, OS 파일 시스템 직접), 끌어 놓기·동시 3·sha256·이어받기
- DB:
  - PostgreSQL·MariaDB·MySQL, 객체 트리
  - SQL 편집기(선택·현재 문장·전체 실행, 문장별 결과 탭, 파라미터)
  - 결과 스트리밍·가상화, 취소, 읽기 전용 모드, CSV/JSON 내보내기
- 가져오기: ssh config·PuTTY
- (사용자 요청 추가) IDE식 도킹 배치 — 트리·편집기·터미널을 끌어 옮기고 합치기, 배치 저장
- 남음(2단계로): 셸 통합 ✓/✗(OSC 133), 터미널 검색·링크·EUC-KR 터미널 인코딩, 이미지·CSV 표 미리보기, 전송 sha256 확인·이어받기·동시 3개, SQL 파라미터(:이름), zsh 폴더 따라가기
- 실측 남음: 진짜 CentOS 6(ssh-dss)·구판 MySQL 5.x·MariaDB 5.5 서버, 사람이 화면을 직접 조작해 보는 확인

## 0.12.1 — 자동완성 되살리기·편집기 다듬기·전체 점검 (2026-11-11)

- 터미널: 칠 때는 목록을 띄우지 않고 Tab 으로 목록(기본으로 되돌림, 설정 "Tab 키 = 셸 완성"이면 Ctrl+Space). 계산 중 온 Tab 은 버리지 않고 차례로(연타로 파고들기). "치다 멈추면 목록" 방식은 ↑↓ 로 고른 뒤에만 Enter 가 넣기
- 셸 통합: 로그인 셸을 알아내지 못해도(exec 거부·느림) bash 일 때만 걸리게 감싼 훅을 보낸다 — 0.12.0 에서 그런 서버는 프롬프트 표식이 없어 자동완성이 통째로 꺼졌다
- 편집기: 글 위 마우스 포인터 I자(앱 전체 cursor: default 를 이어받아 화살표였다), 상태 줄 자동 저장 스위치(멈추면·포커스 떠날 때·둘 다, 자동 저장됨 시각·실패 다시), 미니맵(기본 켬), JSON 문법 오류 표시, 낱말 완성은 두 글자부터·잠깐 멈추면, 팝업 불투명
- 앱을 다시 열면 열려 있던 편집기 탭을 되살린다(다른 서버 칸 파일 제외, 12개까지). 파일 트리 T(여기서 터미널)·L(실시간 보기)
- 전체 점검(영역별 리뷰): sudo 전환·주석 편집으로 고친 내용이 사라지던 것, 펼친 적 없는 폴더에 끌어 놓을 때 묻지 않고 덮어쓰던 것, 서버 안 복사 따옴표(명령 주입), 포워딩 채널 하나가 연결 전체를 멈추던 것, 끊긴 tar 받기를 성공으로 보던 것, PG 트랜잭션 안 행 상한이 커밋을 되돌리던 것, `BEGIN;` 뒤 문장이 합쳐지던 것, 실행 중 Ctrl+Enter, 원격 출력 ack, 한글 프롬프트 자동완성 위치 등
- 다듬기: 파일 트리 머리줄 두 줄·터미널 연동 단추, 상태 줄 잡음 줄이기, Ctrl+W 는 편집기 칸만(Ctrl+Shift+W 는 서버 탭), 우클릭 메뉴 단축키 정렬·키보드·초점 복귀, 글자 아이콘을 그린 아이콘으로
- 남음: 저장 전 바뀐 곳 확인(Orbit 은 늘), 같은 파일 나란히 보기, JSON·XML 정렬을 보기 전용으로, 전송 이어받기 원본 확인, DB 매개변수 바꿔 넣기·필터 중 새 행·PG 열 형식

## 0.12.0 — 서버 ↔ 서버·출력 흐름 제어·터미널 우선 배치 (2026-11-11)
- 다른 서버 칸: 열려 있는 다른 SSH 연결의 트리를 작업대 옆에, 트리끼리 끌어 놓으면 서버 ↔ 서버(중계, sha256·이어 보내기·충돌 시트), 다른 서버 파일 편집
- 출력 흐름 제어: 화면이 그린 만큼(ack)만 더 보낸다(창 512 KB). SSH 는 채널을 멈추지 않고 앱 안에 모으며(최대 16 MB), PTY 는 읽기를 쉰다. 이미 온 출력은 묶어서 보낸다
- 단어 색칠은 보이는 줄만(꾸밈이 쌓이지 않음), 암호·해시 크레이트만 opt-level 3
- 셸 통합: 로그인 셸을 먼저 확인해 bash·zsh 에만 건다(그 밖은 아무것도 치지 않음). clear 대신 주입한 줄의 에코만 걸러 MOTD 가 남는다
- 자원 표시 폴링은 연결당 하나(터미널을 나눠도 한 번만 묻는다)
- 기본 배치 터미널 우선(v3), 도구 막대는 자주 쓰는 것만 + "도구 ▾", 터미널 안 Ctrl+Shift+F·F1 은 터미널 몫, 계정 하나·물을 것 없으면 서버 카드 없이 바로 접속
- 터미널 Ctrl+C/Ctrl+V(Windows Terminal·VS Code 규칙): 고른 글이 있으면 Ctrl+C 복사·없으면 ^C, Ctrl+V 붙여넣기(설정으로 ^V), macOS ⌘C/⌘V, 복사됨·실패 알림
- 남음: A→B 서버끼리 직접 전송(rsync/scp, 망이 닿을 때), 상태 줄을 작업대 한 줄로 합치기
