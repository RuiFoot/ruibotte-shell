# 기능 점검표

웹 작업대(이전 판)가 주던 기능을 사용자 눈높이로 전부 뽑아 이 앱과 하나씩 대조한 결과다(2026-11-05).
표시: `[x]` 있음 · `[~]` 일부 · `[ ]` 없음. 위에서부터 자주 쓰는 순으로 채운다. 채울 때마다 이 문서를 고친다.

집계(대조 시점): SSH 약 300항목 중 있음 85 · 일부 55 · 없음 80 / DB 약 180항목 중 있음 67 · 일부 50 · 없음 51.
원인: 이전 판 편집기는 Monaco 라 자동완성·포맷 같은 기본 기능이 요구 목록에 따로 적혀 있지 않았고, 옮길 때 목록만 보고 옮겨서 빠졌다.
